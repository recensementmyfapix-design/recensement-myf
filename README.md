# Application de recensement des impenses – ZAI de Médina Yoro Foulah (extension 20 ha)

Application de terrain de la Commission départementale de recensement et d'évaluation des impenses (CDREI), mise en place par la DSES / APIX S.A.

- Application : https://recensementmyfapix-design.github.io/recensement-myf/
- Serveur de la mission : Google Apps Script (compte recensement.myf.apix@gmail.com), données dans le classeur « Recensement ZAI Médina Yoro Foulah – Extension 20 ha ».
- Les agents saisissent le code de mission fourni par la DIUF, leur prénom et nom, puis recensent. Les données se synchronisent dès que le réseau est disponible.
